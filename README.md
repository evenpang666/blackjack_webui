# 廿一点 · 局域网 21 点

参考 `../holdem_webui` 的 aiohttp 房间协议、聊天、日志、邀请、会话恢复及结算流程，使用独立的服务端 21 点引擎。

## 启动

- Windows：双击 `start.bat`。
- Linux：运行 `bash start.sh`。
- 脚本准备 uv、Python 3.12 和锁定依赖，随后打开 `http://localhost:8766/`。首次启动需要联网。
- 已有环境也可以 `uv sync --locked`，再使用 `.venv` 中的 Python 运行 `server.py`。
- 局域网玩家访问 `http://房主IP:8766/`，使用房间码加入，或点击房主复制的邀请链接。防火墙需允许 TCP 8766。

本项目使用 8766 端口，可与 8765 端口的德州扑克同时运行。

## 房间与筹码

房主创建房间并作为闲家入座。庄家始终是电脑赌场，不占闲家座位、不转移给房主；每间房最多 5 位真人闲家，1 人即可开局。赌场负责所有赔付，玩家只与庄家比点数，不互相争夺底池。

带入金额为 ¥5–1000，且为 5 的倍数。房主点击「开始下注」，每位本局玩家确认下注或选择旁观，所有人决定后自动发牌。下注通常为 5 的倍数，也可投入全部剩余筹码。中途加入等待下一局。

剩余筹码为零且当前下注结算完毕，才算破产。破产玩家需要重新带入才能参赛；其他牌局进行中可申请下一局重新入座，累计带入计入最终净输赢。下注、赔付、累计筹码均以整数分计算，避免浮点累计误差；小于 ¥5 的余额仍可通过「全部筹码」下注。

聊天、完整牌局日志、日志显隐、邀请链接、房主移出玩家、刷新重连和主动退出后恢复原昵称与余额沿用参考项目。主动退出及断线时，尚未下注者自动旁观，已下注者自动停牌，保留本局结果与筹码；房主主动离开时转交房主权限。可在原浏览器返回原房间，不重复带入。房主在一局结束后点击「结算」，关闭房间并向在线玩家显示最终排行，按剩余筹码减累计带入排序，包括已退出玩家。

## 明确的规则版本

21 点的赌场规则存在可选差异。本项目采用美式暗牌、庄家软 17 停牌（S17）版本，基本规则参考 [Bicycle Blackjack](https://bicyclecards.com/how-to-play/blackjack/)。

- 每局洗一副标准 52 张牌，无大小王。所有房间各用自己的牌副，牌不会跨房间共享。
- 2–10 按面值，J/Q/K 为 10；A 为 1 或 11，服务端自动采用不爆牌的较大点数。
- 先下注，再逐轮发给每位闲家与庄家各两张牌。闲家明牌，庄家一明一暗；暗牌在玩家阶段不发送给任何客户端，包括房主。
- 庄家明牌 A 时提供保险，选择结束后检查 Blackjack；明牌为 10/J/Q/K 时直接检查。庄家 Blackjack 立即结算，防止玩家额外加倍或分牌后才发现庄家 Blackjack。
- 要牌、停牌：超过 21 点立即爆牌，恰好 21 点自动停牌。闲家全部行动完成后，电脑庄家逐张补牌到至少 17 点，软 17 也停牌。
- 加倍：任意两张初始牌允许加倍，补一张后停牌，余额需足够追加同额下注；分牌后也可加倍。
- 分牌：同点数的一对可分为两手（10/J/Q/K 可互分），追加同额下注；最多 4 手。分 A 仅一次，每手只补一张，不能继续要牌或加倍。分牌后的 A+10 只算普通 21 点。
- 晚投降：庄家确认无 Blackjack 后，未分牌且仍为最初两张牌时可投降，退还一半下注。
- 两张未分牌的 A+10 点牌为 Blackjack，净赢下注的 3/2；普通胜利净赢 1 倍。相同点数退回下注；双方 Blackjack 平局；Blackjack 胜过普通 21 点。爆牌先输，即使庄家随后爆牌也不退还。
- 保险是独立下注，金额为原注的一半，需另有足够余额；庄家 Blackjack 时净赔 2:1，否则保险全输，主注独立结算。
- 金额精确至 ¥0.01；Blackjack 产生半分时四舍五入，保险金额与投降退回金额产生半分时向下取分。
- 极端分牌与要牌导致单副牌耗尽时，本局作废、退还主注及保险，记录日志；不引入第二副牌。

庄家行动间隔由房主调节。所有洗牌、发牌、合法行动、赔率和结算都在服务端完成，浏览器只能提交动作。房间仅存内存，服务进程退出后消失；筹码用于游戏记分。

## 验证

安装 pytest 后运行 `python -m pytest -q`。测试覆盖点数、赔率、保险、分牌、加倍、投降、单副牌、筹码守恒、破产重新入座、离开回房、权限和真实 HTTP/WebSocket 房间流程。
